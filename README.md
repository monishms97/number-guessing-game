# 🎯 Number Guessing Game

A simple Number Guessing Game developed in C as part of my C programming learning journey.

## Features

- Random number generation
- User input
- Hint messages (Too High / Too Low)
- Tracks the number of attempts
- Beginner-friendly C project

## Technologies Used

- C Programming
- GCC Compiler
- Visual Studio Code
- Git & GitHub

## How to Run

```bash
gcc number_guessing_game.c -o game
./game
```
